Time

Todo mundo do time vê as mesmas contas e publicações. Cada pessoa nova no InstaFlow ganha o próprio time; para trabalhar junto, convide pelo e-mail. Quem já tem conta entra na hora; quem não tem entra ao criar a conta.

Post for Me

Variações de legenda com IA

O botão ✨ Criar variações, na tela Criar, faz uma legenda diferente para cada conta a partir da sua. Sem IA, ele troca expressões comuns, emojis e a ordem das hashtags. Com IA, cada conta ganha a legenda reescrita de verdade, com o mesmo sentido e os mesmos números, @menções e hashtags.

Criar chave grátis no Google AI Studio →

Aceita Google Gemini (tem plano grátis; recomendado), Groq (grátis), OpenAI, Anthropic ou OpenRouter. A chave fica guardada no servidor e não aparece mais no navegador depois de salva. No plano grátis do Google, os textos enviados podem ser usados por ele para melhorar os produtos.

Uso do mês

Cada conta que recebe uma publicação conta 1. O Instagram limita cada conta a 100 posts via API por 24 h.

API e integrações

Documentação da API →

Com uma chave de acesso, outro sistema (n8n, Make, Zapier, seu site ou app) faz tudo o que o painel faz: listar e conectar contas, subir fotos e vídeos, agendar com legenda e variações por conta, acompanhar o resultado e receber avisos. Cada chave vale só para este time.

Webhooks (avisos para o seu sistema)

O InstaFlow chama a sua URL quando um post sai numa conta, falha, ou termina em todas. Cada aviso vem assinado com o segredo do webhook.

Como funciona

  • Horários sempre em America/Bahia (UTC−3).
  • O Post for Me publica em até 2 minutos após o horário e avisa aqui conta por conta.
  • Fotos fora de 4:5–1.91:1 passam pelo ✂ Ajustar (cortar ou caber inteira) antes de agendar; a foto sai já no tamanho certo e o Instagram não corta nada.
  • Facebook publica em Páginas (cada Página é uma conta); aceita texto, foto, vídeo, Reels, Stories e carrossel só de fotos.
  • TikTok aceita um vídeo ou até 32 fotos (nunca misturados), título de até 85 caracteres e privacidade público/privado. Feed/Reels/Stories não se aplicam.
  • Chaves das contas renovam sozinhas; se uma conta pedir "Reconectar", basta autorizar de novo.
