Como conectar

Instagram

  1. A conta precisa ser Profissional: no app, Perfil → ☰ → Configurações → Tipo de conta e ferramentas → "Mudar para conta profissional".
  2. Entre no Instagram com a conta certa no navegador antes de conectar (a autorização usa a conta logada).

Facebook

Publica em Páginas. Você precisa ser administrador da Página. Na autorização, marque as Páginas que quer usar: cada uma vira uma conta aqui.

TikTok

Perfil pessoal ou de criador. Entre no TikTok com a conta certa no navegador antes de conectar. Se o TikTok publicar como privado, mude a privacidade na tela Criar.

A autorização passa pelo app "Post for Me", nosso parceiro de publicação. Nenhuma senha é guardada.
